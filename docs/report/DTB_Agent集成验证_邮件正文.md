主题：DTB 在 Agent 多轮工具调用场景的集成攻关与验证进展

各位好，

8 月 13 日至 9 月 4 日，我们围绕 DTB 接入 Agent 多轮工具调用开展了持续的工程排障与回归验证，重点解决了思考状态切换、流式传输、工具解析和投机解码叠加时的兼容性问题。

本轮完成的主要工作包括：

- **修复回合边界和重复生成。** 统一思考结束与工具开始的状态迁移，解决 XML 泄漏、冗余 role，以及 tool delta 后继续输出 content 的问题。
- **修复投机合批下的工具解析。** 对齐文本与 token 的交接语义，保留原生终止事件，并修复工具解析器的同批收尾和连续多工具处理，消除工具前缀丢失、参数 JSON 缺闭合括号等故障。
- **消除停止条件对合法正文的误伤。** 移除最终答案中的内部思考 stop，将流式思考边界迁移到结构 Token ID，并补齐原生 reasoning parser 对边界同批正文的保留逻辑。

验证过程中，早期主样例的异常随分层修复逐步收敛；扩大 Agent 上下文后发现的新故障也继续定位关闭。其中一组 300 条 DTB 回放的非法参数 JSON 从 133 条降至 0 条。**最新 120 条 Vanilla/DTB 响应的工具流协议异常均为 0；60 条 DTB 的公开思考正文全部保真，48 次原故障触发条件下的 344 个字符完整保留。** 历史真实 MTP 回放也验证了同批参数收尾修复，兼容方案不依赖关闭投机解码。

目前，已覆盖场景未再观察到上述框架传输与解析问题。该结论与模型工具选择、缺参及最终任务质量分开统计，也不代表时延收益已达标。下一步将冻结修复版本，开展完整 Agent 任务的质量与端到端时延回归。

详细过程和证据见随附技术博客及一页时间轴。
