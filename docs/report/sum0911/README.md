## 维护和复算

修改技术博客后，同步邮件和 `sources/build_report.mjs` 中的展示文案，再重新生成邮件/PPT。来源 SHA-256、逐任务指标、分布与案例 phase 保存在 [evidence.json](sources/evidence.json)。

`sources/collect_evidence.py` 只读已有实验数据，核对任务输入 hash、唯一请求 ID、请求与任务耗时总和、分档成员、原文片段及案例 phase，不调用模型。`sources/build_report.mjs` 使用已安装的 artifact-tool 和 marked 生成原生数据图和四页 PPT，并运行包结构/版式校验。运行时路径按本工作区配置；跨机器需修改路径或使用同等运行时。每次先输出独立校验版本，再保存旧 PPT 到私有构建目录并更新交付文件。

本次未新增目标服务器性能测试，也未发送邮件或发布网站。
