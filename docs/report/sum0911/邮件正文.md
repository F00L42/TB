主题：DTB 阶段性进展：Agent 工程可用，端到端 LLM 耗时下降 11.57%

各位好，

本阶段（8.10~9.11）围绕动态思维链压缩技术 DTB 接入 Agent 场景的工程可靠性与思考压缩效果进行了开发与验证，主要进展如下。

**一、解决多轮工具调用中的关键工程问题。** 通过算法集成与原生解析器协同修复，解决回合边界错位、工具前缀丢失、参数 JSON 不完整及停止条件误伤正文等问题。最新定向回放的 300 条响应未检出工具流协议异常，思考正文全部保真。后续完整端到端测试中未检出任何协议故障，且兼容投机解码等原生特性。

**二、任务通过率不下降，reasoning token与端到端时延双降。** 9 个任务中，Vanilla run-06 与 DTB run-08 的最终 DT 全通过任务数均为 4/9；累计 LLM 端到端耗时从 2,902.455 秒降至 2,566.697 秒，减少 **11.57%**；可见 reasoning token 从 52,112 降至 39,759，减少 **23.70%**。

针对Agent辅助研发场景短思考极多、长思考极长的分布特征，我们选择“抓大放小”的解决方案：短请求保持原生完成，少数长思考才支付试答与重启成本。

**三、可扩展到更多存在冗余思考的模型。** 置信度阈值、短试答与原生旁路的工程实现可以无缝迁移，但针对特定模型可能需适配协议、标定阈值。当前跨模型收益尚待实测。近期将优先获取更多思维链样本，扩展应用模型。
