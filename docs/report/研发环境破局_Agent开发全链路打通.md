本仓库以 SPEC（规范驱动开发）思想重塑 Agent 业务研发：先在 `AGENTS.md` 中固化项目目标、仓库地图、性能口径、证据规则、集成约束和验证边界，再通过 `docs/design/`、`docs/debug/` 将设计决策、问题跟踪、实验方案和开发任务沉淀下来，代码与 vLLM 集成补丁按同一套接口和状态机落地，服务器执行结果则以 `manifest`、请求级 JSONL、phase 账本、环境快照、汇总 CSV 和结果复盘统一回写 `docs/log/`，从而把设计、跟踪、开发、验证、汇报统一到同一份可追溯事实源。Agent 可以沿着“规范—设计—源码—结构化日志—复盘—下一轮任务”持续接力，快速定位隐藏 probe、prefill、controller CPU 等真实成本，推动研发环境破局、全链路打通和敏捷调试闭环。已有固定配置的重复实测显示：端到端平均时延较对应基线降低约 20.6 秒（31.48%），可见输出减少 2,511 token（55.48%），并保持 JSON 结构正确，体现了规范、数据与代码联动带来的研发效率提升和端到端优化收益；其中性能数字来自现有实验记录，正式语义质量结论仍应以补齐后的质量评分为准。
