在UNC（Unified Core Network）及移动通信领域中，**PLMN** 与 **PSTN** 是两种完全不同的网络体系，主要区别如下：

### 1. 全称与基本定义
| 缩写 | 全称 | 中文名称 | 定义 |
|:---|:---|:---|:---|
| **PLMN** | Public Land Mobile Network | 公共陆地移动网络 | 由国家或授权运营商建立，为公众提供**陆地移动通信业务**的网络。 |
| **PSTN** | Public Switched Telephone Network | 公共交换电话网络 | 传统的**固定电话网络**，采用电路交换技术，主要提供语音通信服务。 |

### 2. 核心区别对比
| 维度 | PLMN（移动网） | PSTN（固网） |
|:---|:---|:---|
| **网络类型** | 无线网络（2G/3G/4G/5G） | 有线固定网络 |
| **用户终端** | 手机、CPE、物联网模组等移动终端 | 传统固定电话机、传真机等 |
| **唯一标识** | **PLMN ID = MCC(3位) + MNC(2/3位)** | 电话号码（遵循 E.163/E.164 编号计划） |
| **用户接口** | 无线空口（Um/Uu/NR等） | 模拟用户线（POTS，双绞线） |
| **信令体系** | SS7、Diameter、HTTP/2（SBI） | 带内信令（DTMF）或 TUP/NUP |
| **移动性管理** | 支持切换、漫游、位置更新 | 无移动性管理（固定位置） |

### 3. 在UNC核心网中的关系
* **PLMN 是UNC的服务对象**：UNC核心网（如AMF/SMF/MME等）主要基于 PLMN 标识（MCC+MNC）来识别用户归属（HPLMN）、判断漫游属性（VPLMN）、配置业务策略和计费规则。
* **PSTN 是外部互通网络**：当移动用户需要呼叫传统固定电话，或固定电话呼叫移动用户时，UNC会通过 **MSC/IWF（互通功能）** 实现 PLMN 与 PSTN 之间的信令转换、 codec 适配和回声抑制，完成跨网通信。

### 4. 总结
* **PLMN** 代表**移动通信网络**，核心网运维中配置 HPLMN、漫游 PLMN、策略控制等均围绕它展开。
* **PSTN** 代表**传统固定电话网络**，在核心网中通常作为外部互通网络出现，涉及语音互通（Interworking）场景。
