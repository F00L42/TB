# ALM-5525 容器资源过载

## 告警解释
当容器资源占用大于用户设定的告警阈值时，产生此告警。
当容器资源占用小于或等于用户设定的清除阈值时，清除已产生的此告警。可以通过MML命令`SET CNTRESTHD`设置阈值。
在告警上报并且容器发生复位的场景下，需要等待业务配置的资源检测任务启动后，并且满足上述告警清除的条件下，才可清除此告警。

## 告警属性

| 告警ID | 告警级别 | 可自动清除 |
|---:|:---|:---|
| 5525 | 重要告警 | 是 |

## 告警参数

| 参数类别 | 参数名称 | 参数含义 |
|:---|:---|:---|
| 定位信息 | 网元ID | 用于标识资源超阈值触发告警的进程所属的网元ID |
| 定位信息 | 资源名称 | 产生告警的资源类型，支持cpu、memory、disk partition、inode |
| 定位信息 | 容器ID | 容器全局唯一身份信息 |
| 附加信息 | 当前使用情况 | 产生告警时容器实际占用资源的情况（CPU时100%表示1核） |
| 附加信息 | 异常分区 | 磁盘分区告警时上报异常分区路径 |
| 附加信息 | 告警阈值 | 产生告警时设定的阈值 |
| 附加信息 | 清除阈值 | 消除告警时设定的阈值 |
| 附加信息 | 资源配额 | 容器允许占用资源的最大值 |
| 附加信息 | 告警源 | 上报告警所属的服务 |

## 对系统的影响
容器资源占用超阈值表明进程可能异常，承载业务可能受损，所在节点可能因资源紧张影响其他业务。

## 可能原因
- 告警阈值设置不合理
- 产生告警的容器发生异常

## 处理步骤
1. 登录OM Portal，选择"应用管理 > MML"，执行`DSP CNTRESSTAT`（资源名称来自告警定位信息），检查告警阈值是否大于进程正常运行消耗最大值

   - 否 => 执行`SET CNTRESTHD`调整阈值至合理值后转步骤2
2. 等待3分钟
3. 查看告警是否恢复
   - 是 => 处理完毕
   - 否 => 转步骤4
4. 收集告警信息："监控分析 > 告警管理 > 活动告警"按告警ID搜索后导出
5. 收集日志信息："监控分析 > 运行日志 > 服务日志收集"收集OpsAgent和告警服务日志（三方CaaS场景需进入"日志下载"页面批量下载）
