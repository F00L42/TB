最终回答：


确定终端IP地址由哪个网关（或DHCP服务器）分配，通常可以从终端侧、服务端和网络设备侧三个维度进行排查。以下是常用的定位方法：

### 1. 终端侧查询（查看默认网关）
终端获取IP地址的同时，通常会收到默认网关（Default Gateway）信息。直接在终端执行路由查询命令即可确认：
- **Linux/Unix**：`ip route show` 或 `route -n`，查看 `default via x.x.x.x` 中的网关IP。
- **Windows**：`ipconfig /all` 或 `route print`，查看“默认网关”字段。
- **移动端/物联网终端**：查看网络详情中的网关字段，或通过抓包查看DHCP ACK报文中的 `Option 3 (Router)` 字段。

### 2. DHCP服务器侧查询（查看地址租约表）
如果IP是通过DHCP动态分配的，DHCP服务器会记录完整的租约信息（Lease Table）：
- 登录DHCP服务器管理界面或执行查询命令（如 `display dhcp server lease` 或Web端“监控DHCP”）。
- 根据终端IP或MAC地址筛选租约记录，记录中通常会显示**分配接口（Interface）**或**地址池名称**，该接口所属的设备即为分配网关/服务器。

### 3. 网络设备侧排查（ARP表与DHCP Relay）
- **查询ARP表项**：在疑似网关设备上执行 `display arp brief ip <终端IP>`。如果存在该IP与MAC的映射关系，且接口为终端接入侧，则该设备极可能是其网关。
- **检查DHCP Relay（中继）配置**：在跨网段DHCP场景中，终端请求会经过中继设备。DHCP报文中的 `giaddr` 字段填写的是中继接口的IP地址。通过抓包或查看中继日志获取 `giaddr`，即可定位负责转发请求的网关接口。

### 4. 核心网场景专项定位（5GC/EPC）
在云核心网环境中，终端IP分配机制与传统网络略有不同：
- **SMF/UPF分配**：5GC中IPv4/IPv6地址通常由SMF分配或通过UPF的NAT功能映射。可通过运维平台查询对应用户（SUPI/GPSI）的PDU会话信息，查看绑定的UPF地址及分配IP。
- **外置DHCP服务器**：若配置了外置DHCP，SMF会作为DHCP Client代为申请。此时需结合SMF会话日志与外置DHCP租约表交叉比对。
- **NAT映射追溯**：如果终端使用的是私有IP，需查询UPF或专用NAT网关的会话映射表（`display nat session`），根据私有IP反查分配该地址的业务网关。

### 5. 抓包分析（终极手段）
在终端接入链路或网关接口进行抓包，过滤DHCP流量（`bootp` 或 `udp port 67 and 68`）：
- 观察 `DHCP Offer` 和 `DHCP Ack` 报文的源IP地址，该源IP即为响应请求的DHCP服务器/网关地址。
- 结合 `Option 54 (Server Identifier)` 字段，可明确标识出具体的分配服务器。

根据实际网络架构（传统接入网、数据中心或5GC核心网），选择对应的排查路径即可快速定位IP分配源头。如需针对具体网元命令或日志分析，可提供设备类型进一步说明。
