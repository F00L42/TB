## 1. 停止跨分区用户迁移任务（STP MIGRATION）

**命令格式：**
```
STP MIGRATION: TASKID=<任务ID>;
```

**说明：**
- 用于停止正在执行的跨分区用户迁移或回退任务
- TASKID为必选参数，需通过执行 `DSP MIGRATION` 命令查询获得
- 执行该命令后，部分用户已迁移至迁入分区，剩余用户保留在原迁出分区，对用户业务无影响

**使用示例：**
```
STP MIGRATION: TASKID=5;
```

---

## 2. 停止用户数据迁移任务（STP USERTRANS）

**命令格式：**
```
STP USERTRANS:;
```

**说明：**
- 用于停止正在执行的用户数据迁移任务
- 同一时间只允许一个用户数据迁移任务执行
- DMA收到停止请求后，会继续完成本轮正在处理的用户数据，停止迁移任务将在下一轮生效
- **注意：** CloudDB和UDR的混合组网场景不支持通过此命令启动用户数据迁移

**使用示例：**
```
STP USERTRANS:;
```

---

## 注意事项

1. 以上命令均属于**高危命令**，执行前需与华为技术支持确认
2. 执行 `STP USERTRANS` 成功后，隔离的DSU并未恢复，需手工执行 `MOD SEGSTATE` 命令恢复隔离模块状态
3. 只能停止状态为 "Running" 的迁移任务，需先通过 `DSP MIGRATION` 确认任务状态
