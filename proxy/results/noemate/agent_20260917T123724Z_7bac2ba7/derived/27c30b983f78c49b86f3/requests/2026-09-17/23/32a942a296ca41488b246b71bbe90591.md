---

## 一、DHCP 方式分配

终端通过 DHCP 协议获取 IP 时，网关信息由 DHCP 服务器统一分配：

1. **查看终端 DHCP 租约信息**
   - Windows：`ipconfig /all` 查看 "DHCP Server" 字段
   - Linux：`dhclient -v` 或查看 `[REDACTED_PATH] 下的租约文件
   - 终端获得的默认网关（Gateway）即为 DHCP 服务器在 Option 3 中下发的地址

2. **排查 DHCP 服务器配置**
   - 在交换机/路由器的接口上，DHCP 服务器通过 `dhcp server gateway-list` 命令预配置分配给客户端的默认网关地址
   - 若接口配置了 VRRP 虚 IP 且未显式配置 `gateway-list`，DHCP 服务器会使用 VRRP 虚 IP 作为网关分配给客户端
   - 若未配置 VRRP，则使用接口实 IP 作为网关

3. **抓包分析**
   - 抓取 DHCP Discover/Offer 报文，Offer 报文中的 Option 3（Router）字段即为分配的网关地址
   - Option 54（Server Identifier）字段即为 DHCP 服务器地址

---

## 二、5G 核心网场景

在 5G 核心网中，用户终端（UE）的 IP 地址分配主要有以下几种方式：

| 分配方式 | 分配主体 | 说明 |
|---------|---------|------|
| UPF 分配 | UPF | UPF 根据 DN 网络配置从地址池分配 IP |
| DHCP 服务器分配 | 外部 DHCP Server | UPF 透传 DHCP 报文，由 DHCP 服务器分配 |
| LNS 服务器分配 | LNS 网关服务器 | 用于 L2TP 远程接入场景，LNS 与 UPF PPP 协商后将 IP 传递给 UPF |

**确定分配网关的方法：**
- 查询 UPF 上的用户会话信息，查看会话绑定的 IP 地址及分配来源
- 检查 DHCP 服务器日志，确认是否为该终端发放过地址
- 在 L2TP 场景下，查询 LNS 服务器的 PPP 会话记录

---

## 三、通用排查思路

1. **arp 命令**：在终端执行 `arp -a` 查看默认网关的 MAC 地址，确认实际通信的网关设备
2. **路由追踪**：执行 `tracert`（Windows）或 `traceroute`（Linux）查看第一跳网关地址
3. **查询网络设备**：在疑似网关设备上查看 DHCP 租约表或 ARP 表，确认是否为该终端分配过 IP

---

**总结：** 终端 IP 对应的网关由分配机制决定。DHCP 场景下网关由 DHCP 服务器统一下发；5G 核心网场景下需根据 UPF、DHCP 服务器或 LNS 的会话记录来判断分配主体。
