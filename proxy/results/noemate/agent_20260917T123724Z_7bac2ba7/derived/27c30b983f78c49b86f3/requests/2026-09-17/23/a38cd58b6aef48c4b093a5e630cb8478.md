## 核心排查思路

在多云核心网或多UDG部署场景中，可通过以下方式追溯IP分配来源：

### 1. 查询会话信息确认分配方式

在UDG上执行 `DSP SESSIONINFO` 命令查看终端会话详情：

```
DSP SESSIONINFO:QUERYTYPE=IMSI,IMSI="4600001234***";
```

关键输出字段：
- `IPv4 PDP address`：终端获得的IP地址
- `IPv4 Address type`：IP分配类型
  - `UPF ALLOC IP ADDRESS`：由UDG本地UPF分配
  - `EXTERNAL ALLOC IP ADDRESS`：由外部服务器（DHCP/RADIUS等）分配

### 2. 追溯地址池归属

若为UPF分配方式，进一步查询该IP所属的地址池组配置：

```
LST POOLGRPMAP:POOLGROUPNAME="poolgroup1";
```

通过地址池组与DNN、位置区、SMF Node ID的绑定关系，可判断该会话由哪个UDG实例处理。

### 3. 多UDG场景下的定位方法

| 方法 | 说明 |
|------|------|
| **IP段规划法** | 若各UDG配置的地址池段不重叠，可根据IP地址直接判断归属UDG |
| **会话查询法** | 在候选UDG上逐一执行`DSP SESSIONINFO`，返回结果的UDG即为分配者 |
| **SMF Node ID映射** | UPF分配时可基于SMF Node ID绑定地址段，通过SMF定位对应UDG |

### 4. 其他分配方式说明

- **UDM分配**：静态IP存储在UDM签约数据中，不依赖UDG本地地址池
- **SMF分配**：由SMF统一分配，需查询SMF侧配置
- **DHCP/RADIUS分配**：由外部服务器分配，UDG仅透传

## 建议操作步骤

1. 先在疑似UDG上执行 `DSP SESSIONINFO` 查询该终端会话
2. 根据 `IPv4 Address type` 判断分配方式
3. 若为本地分配，通过 `LST POOLGRPMAP` 确认地址池配置
4. 结合网络地址规划文档，最终确定IP分配来源UDG

当前知识库未提供更自动化的跨UDG IP溯源工具说明，如需进一步排查建议收集会话信息并联系技术支持。
